# Trav X - 360° Travel Agency Management System

🔗 [GitHub Repository](https://github.com/tharukaGamage01/Serendia.git)

📍 University of Westminster

A comprehensive full-stack travel agency management platform built with modern architectures. The system streamlines travel operations through integrated inquiry management, AI-driven itinerary generation, and complex financial calculations. Built with Next.js 16 and Supabase, it features real-time progress tracking, multi-role dashboards (admin, agent, viewer), and automated document processing for invoices, vouchers, and costing sheets. The platform includes advanced functionality such as automated PDF generation via Puppeteer and Excel report exports, providing a scalable solution for modern travel agencies.

Key Technologies:

**Frontend**: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS, Radix UI

**Backend & Database**: Supabase (PostgreSQL + Auth + RLS), Edge Functions

**Document Processing**: Puppeteer, Puppeteer-core, ExcelJS (Invoices, Vouchers, Costing Sheets)

**Real-time & State**: Supabase Real-time, Zod validation, date-fns

**Infrastructure**: Vercel Deployment, Supabase Cloud

Core Features:

- **Complete Inquiry Capture**: Management of client requirements, traveler details, and trip preferences.
- **AI-Driven Itinerary Creation**: Detailed multi-day travel planning with automated content generation.
- **Comprehensive Financial Suite**: Automated generation of Invoices, Payment Vouchers, and Driver Logs.
- **Dynamic Costing Sheets**: Real-time mileage and price calculations for complex travel packages.
- **Role-Based Access Control**: Secure environment with granular permissions for admins, agents, and viewers.
- **Professional Document Exports**: Clean, client-ready PDF and Excel outputs for all travel documents.
