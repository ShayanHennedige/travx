# 13. User Guide

## 13.1 Minimum Platform Specification

* Modern browser: Chrome, Edge, Safari, or Firefox current version.
* Internet connection: stable broadband connection for cloud access and document downloads.
* Local development runtime: Node.js 20 or later and npm.
* Database/backend: Supabase project with PostgreSQL, Auth, Storage, and Realtime enabled.
* Deployment: Vercel project connected to the repository.

## 13.2 Installation and Local Demonstration

1. Download or clone the project repository from the submitted source code link.
2. Install dependencies using npm install.
3. Create a .env.local file using the placeholder variables provided in the project README. Do not place real API keys or secrets in this report.
4. Run the development server using npm run dev.
5. Open the local application address in a browser and log in using the demonstration user credentials provided separately.
6. Test the inquiry-to-document workflow by creating an inquiry, generating an itinerary, preparing a costing sheet, and exporting a PDF or Excel file.
